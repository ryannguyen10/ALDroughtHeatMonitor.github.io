This is a demonstration model built for prototyping purposes. County boundaries are real (U.S. Census TIGER geography); drought index values are synthetically generated to illustrate a plausible seasonal dry-spell pattern and do not reflect actual measured conditions. A production version would source live index values from the U.S. Drought Monitor, NOAA CPC, or a bias-corrected model output such as the ECMWF S2S / ERA5-Land pipeline.
